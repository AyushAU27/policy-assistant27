# AI usage

AI assistance was used during development and verification.

## What the AI did

- Helped inspect the assignment and repository requirements.
- Helped review the deterministic document-loading, dated-rule, parsing, routing,
  arithmetic, citation, CLI, test, and evaluation code.
- Helped run the unit tests, evaluation suite, Python compilation check, and CLI
  smoke test.
- Helped identify documentation and submission requirements that needed to be
  preserved, including this disclosure file.

## What I did

- Supplied the policy documents and assignment materials.
- Reviewed the implementation and its documented decisions.
- Ran the project and checked the resulting answers and validation output.
- Decided what to submit and which repository to use.

The assistant itself does not call an LLM. It is deterministic, offline, and
performs arithmetic in code.
